About DestroCipher

An inside look at the privacy architecture and the interlocking dual-prime mathematics driving this system.

🛡️ The Zero-Knowledge Privacy Model

Traditional data security models require you to trust a company's server with your passwords and private text. This web application operates on a strict Zero-Knowledge client-side architecture.

When you type a message or enter a secret passphrase key, your data never crosses the internet. It is never sent to a cloud server, and it is never saved to a database. The entire cryptographic process runs locally inside your device's browser window via native JavaScript code. Once you close your browser tab, your key and message are instantly erased from system memory.

🧮 The Core Mathematical Mechanics

To eliminate repeating character patterns and withstand modern dictionary brute-force scripts, this web app implements an advanced Base-95 Interlocking Dual-Prime Stream Cipher.

1. Positional Core Base Conversion

Your typed text passphrase is converted into a single massive integer representation (Key value $k$). This value acts as the foundational starting seed for our background calculation engines.

2. Interlocking Engine State Equations

For each single text character positioned at index counter ($i$), two completely separate mathematical engines iterate independently using two unique large prime number boundaries (997 and 1009):

Xi = (Xi-1 × 31 + θi-1 + i) mod 997

Yi = (Yi-1 × 41 + θi-1 + i) mod 1009

Both state outputs then instantly fuse together to extract an unpredictable, non-repeating dynamic mathematical letter shift integer ($S_i$):

Si = ((Xi + Yi) mod 94) + 1

3. Reversible Stream Processing Operations

By swapping out standard alphabetic frameworks for a full 95-character printable ASCII suite, the core calculations safely encrypt and flawlessly reverse your target files:

Encryption: θi = ((λi + Si - 1) mod 95) + 1

Decryption: λi = ((θi - Si - 1 + 95) mod 95) + 1

Where λ (Lambda) represents the numerical input value, and θ (Theta) represents the final output character value displayed on your clipboard interface screen.

⚠️ Critical Operational Conditions

  • No Key Recovery Channels: Because we do not log accounts or maintain server tracking systems, forgotten passphrases cannot be recovered. Keep your keys safe.
  • Dynamic avalanche output: Changing even a single character or symbol inside your passphrase completely reshuffles the calculated stream engines, turning your decrypted result into broken data garbage.
